## 目标流程

1. **选择文件**：立即本地预览。已登录自动上传并检查；匿名保留本地草稿，点击一次登录后自动继续免费准备。
2. **调整设置**：自动检测为默认。切换普通/PRO、绘制精修或视频固定区域，自动准备有效报价。选区更新采用短暂合并，避免每次移动都发请求。
3. **点击一次处理**：主按钮明确显示操作、完整费用及单位；旁边显示余额和输出。没有独立检查、费用查看或确认弹窗。只有点击此按钮才创建处理任务。
4. **查看并下载**：任务自动更新到结果；保留对比、下载和允许的精修入口。再次处理仍须点击带费用的新操作。

从选完文件到开始处理，常规路径的必要业务点击由三次减为一次。检查和报价耗时仍真实显示，不将后台耗时表述为瞬时处理。

## 状态及费用不变量

| 状态 | 用户看到的反馈 | 允许的动作 |
| --- | --- | --- |
| 本地文件 / 匿名 | 本地预览、Sign in to continue | 登录、替换或丢弃草稿；零上传、零付费提交。 |
| 上传 / 检查 | 自动准备状态、上传进度 | 免费准备；失败就地重试；刷新继续已有上传。 |
| 自动报价 | 正在计算费用 | 修改设置使旧报价失效；旧响应不能覆盖新设置。 |
| 有效报价 | 完整费用、余额、输出与处理按钮 | 一次明确点击提交；余额不足禁用并就地解释。 |
| 选区改变 | 原报价立即失效 | 选区完成后准备新 mask 与报价，即使选区始终非空也必须更新。 |
| 报价过期 | 自动刷新费用 | 刷新不提交任务；新费用仍需用户点击。 |
| 提交中 / 确认不明 | 单一任务状态或 Check submission | 禁止换文件、模式及选区；原报价和幂等 key 恢复，不重复预留。 |
| 失败 / 退回 | 明确错误和实际额度状态 | 免费更新报价；任何新处理仍需明确点击。 |

服务器的检查、报价、准入、幂等、费用预留、退款和 Provider 契约保持既有边界；客户端不能跳过兼容性或余额校验。
