Open the presentation in Gamma, choose Share and then Export, and select PDF, PowerPoint or PNG. Gamma’s web help also documents Export in the deck’s three-dot menu. Before downloading, check whether the selection includes all cards or only the current one. Open the saved file in its destination app before sharing it.

Use PDF for a stable reading copy, PPTX when the recipient needs to make slide changes, and PNG when the job calls for individual images. Keep the Gamma original if the deck contains interactive elements, embeds or an online layout you need to preserve.

## Choose the format for the handoff

| **What the recipient needs** | **Format to start with** | **What to verify** |
| --- | --- | --- |
| Read or print the deck | PDF | Page order, margins, links and readability |
| Edit the slides in PowerPoint | PPTX | Fonts, text wrapping, tables and charts |
| Import into Google Slides | PPTX | Import result and the saved version in Slides |
| Use one card as a picture | PNG | Pixel dimensions, crop and visible marks |
| See the original web experience | A Gamma link with appropriate permissions | Access, interactive elements and embeds |

For example, a printed workshop packet and a reusable teaching deck are separate deliverables. Export the packet to PDF and verify the smallest table text at print size. Export the source for the next instructor to PPTX and check that a sentence and a table cell can actually be edited. If both are required, give each a filename that identifies its use.

PDF is usually a simpler choice when nobody needs to change individual elements. A PowerPoint file is a better starting point for editing, but there can still be differences in how charts, fonts or layout features translate. PNG is useful for placing one card in a newsletter or asset library. Its text and shapes are pixels in that copy.

## Export a Gamma presentation on the web

### Preview the deck in Present Mode

Open the Gamma you are allowed to export and enter Present Mode. Gamma says the download follows that view, so check it before looking for a formatting problem in the exported file. Review the longest card, the busiest chart, any interactive embed and the first and last cards. If a card depends on scrolling or dynamic content, decide how it should read in a static file.

### Open Export and choose the card range

*Gamma’s single-card Export menu lists its available file types.*

[Gamma — Interface source](https://help.gamma.app/en/articles/8022861-what-s-the-easiest-way-to-export-my-gamma)

Use Share and then Export in the web editor. The three-dot menu is another documented entry. Inspect the card selection before you choose a format. For a full deck, select all cards. For one card, select it from the export controls or use the documented download action in that card’s menu. If the recipient needs a specific subset, verify the exact options your current interface exposes and confirm the exported page count.

### Select PDF PPTX or PNG

Choose PDF, PowerPoint or PNG based on the handoff. Adjust image quality only when the delivery needs a different balance of file size and clarity. Gamma documents editable table export for PPTX, with a setting that can switch to a visual representation. Keep tables editable when the recipient needs to change their data or styling. If appearance matters more, compare a PDF proof with the editable copy.

A larger image setting can make photographs clearer, but it cannot turn an image of a chart into an editable chart. Check both the visual result and the required editing action separately. A PDF can be sharp while a chart is unavailable as live data.

### Open the file from its saved location

Watch for the browser download, then open the saved file rather than judging the result in the Gamma tab. Rename the file with the version and destination if the download name is unclear. Count the pages or slides and confirm the order. On a company device, save the copy where the recipient or presentation computer can reach it through the approved workflow.

If the export does not appear, check the browser’s downloads and any export delivery notice Gamma provides. Confirm that you have the required access to the deck. Try a single card before repeating a large export. A small export can help separate a deck-specific problem from a browser or account issue.

## Export from the mobile app or save one card

Gamma’s mobile guide describes opening Share, selecting Export, choosing a format, and using the device’s share sheet to save the result. Finish the save action in the destination you select. Closing the share sheet before picking a destination may leave no local file. Reopen the saved result from Files, Drive or the app you used to save it.

The mobile workflow is useful for sending a quick full-deck copy. The web interface is the more appropriate route when you need fine control over individual cards or when the mobile app does not offer the required export. Use the card’s download action on the web when a colleague needs one image rather than the entire presentation.

For a portable Google Slides handoff, use Gamma’s documented PPTX route and check the file after importing it into Slides. If a direct Slides export appears in your account, verify its destination and the deck it creates before relying on it. A downloaded PPTX and the editable Google Slides version are two files. Tell reviewers which one to edit and keep the other as a reference if you need to compare formatting.

## Fix common export problems

![Gamma’s export guidance shows the font reminder for opening a PowerPoint file.](/uploads/how-to-export-gamma/image2.png)

*Gamma’s export guidance shows the font reminder for opening a PowerPoint file.*

[Gamma — Interface source](https://help.gamma.app/en/articles/8022861-what-s-the-easiest-way-to-export-my-gamma)

Compare an exported page first with Gamma Present Mode. If both show the same overflow, fix the source card before changing export settings. Shorten the longest block, split dense material across two cards, and make sure the chart labels have space. If the presentation looks correct in Gamma but text wraps differently in PowerPoint, check the fonts available on the target machine and try a supported substitute in a duplicate.

For distorted or undersized content, review Gamma’s documented scaling options and test one representative card. Avoid applying several changes at once. Record the range and format used for the test so the next export is comparable. If a card contains an embed, prepare a static fallback, a clear link or a separate asset as appropriate to the recipient. Confirm which version should be used offline.

For a final client handoff, open the file on the device that will present it. Check the title, the densest card, the appendix, speaker notes where relevant, and links that must work. For PPTX, select and edit one text box and one table cell in a copy. For PNG, preview the image at the size it will appear in the destination. For PDF, check pages and print readability.

For a single chart image, open the exported PNG beside the original and check the numerical labels and units. The chart may be legible in Gamma but too small once the image sits in an email or article. If the chart needs to be read at a narrow width, simplify the source card or provide an accompanying text summary rather than upscaling a small file.

## Separate Gamma branding from image cleanup

If the exported file carries Gamma branding, use the applicable plan and export controls described in Gamma’s own help. The identity of the exported document and its rights are separate from a visible mark on a particular photo. If you only need to update an authorized product image with an expired promotion or an event photo carrying an old date, edit that source image before replacing it in the deck.

The browser image workflow can help you review these photos before replacing them in a presentation.

- **Local image preview.** Confirm that you selected the source picture rather than the exported slide.
- **Automatic overlay cleanup.** Try reconstructing the visible mark area on a compatible still.
- **Original and result comparison.** Inspect whether the new pixels match the rest of the photo.
- **Eligible brush refinement.** Check availability and cost before a follow-up pass on a small defect.

## Frequently asked questions

### Why did Gamma export one card instead of the full deck

Check the card selection in the export menu. Choose all cards for the full deck and confirm the downloaded page count.

### Which Gamma export keeps slides editable

PPTX is the appropriate starting format for PowerPoint. Test the downloaded copy by selecting the actual objects the recipient needs to change.

### Can I export to Google Slides directly from the mobile app

Gamma’s documented handoff uses PPTX and then imports it into Google Slides. Use the web route when the mobile app lacks the required option.

### Why does an export look different from the editor

Gamma exports from its presentation view. Compare that view first, then investigate scaling, fonts, charts and content that depends on web features.

## Conclusion

Choose the format by what the recipient needs to do, check the card range and open the saved copy. Keep the original Gamma deck for features that depend on its online presentation.
