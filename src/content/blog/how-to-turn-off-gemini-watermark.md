Google introduced the Media Watermark setting in August 2026, giving Gemini Apps users more control over visible watermarks on newly generated images, videos, and music-related visuals. If you want to turn off the Gemini watermark, the first step is to change this setting before you create new media.

The key distinction is between a new creation and a file you already downloaded. The setting prevents new visible marks where available; it does not edit existing files or disable invisible provenance signals such as SynthID.

## Quick Answer: How to Turn Off Gemini Watermark

Open [Gemini Apps](https://gemini.google.com/), go to **Settings > Media Watermark > Off**, and generate a new image to confirm the result. This controls visible marks on future Gemini Apps media—not watermarks on previously saved files.

## How to Turn Off Gemini Watermark on Web and Mobile

Use the native setting first if you are preparing to create something new. The menu location differs slightly between the desktop and mobile interfaces, but the setting has the same purpose.

### Turn Off Gemini Watermark on Desktop

1. Visit gemini.google.com and sign in to the Google account you use to generate media.

2. At the lower left of Gemini Apps, open Settings and choose Media Watermark.

3. Switch Media Watermark to Off before generating your next image, video, or music-related visual.

4. Generate a new image and inspect the downloaded result for the visible Gemini mark.

### Turn Off Gemini Watermark on Android, iPhone, or iPad

1. Open the Gemini app or visit gemini.google.com on your phone or tablet.

2. On the left, tap Menu, then Settings > Settings.

3. Find Media watermark and switch the setting off.

4. Create a new test image. Check this new result, rather than an image generated earlier.

The exact icon appearance can vary by app version. For platform-specific instructions, see [Google's Gemini Apps watermark help page](https://support.google.com/gemini/answer/17405358).

### How to Confirm the Setting Worked

A quick test helps separate a settings issue from a watermark already present in an older file:

1. Check that Media Watermark is Off in the account you are using.

2. Generate a simple new image (for example, a coffee cup on a wooden desk) and download it.

3. Inspect the visible mark area. If a watermark remains on the new download, use the checks in the troubleshooting section below.

## What Changes After You Turn Off Media Watermark?

The setting controls the visible layer on new Gemini Apps creations. It does not switch off AI-origin signals or retroactively rewrite previously generated media.

| **Media or identifier** | **What changes when Off** |
| --- | --- |
| New Gemini Apps images | The visible Gemini mark is not added when the setting is available and working. |
| New Gemini Apps videos | The visible overlay is controlled by the same setting. |
| Music-related visuals | The visible watermark on the visual player is controlled by this setting. |
| Invisible SynthID / C2PA | Unchanged. Invisible provenance and Content Credentials remain. |
| Images or videos already saved | Unchanged. The existing file is not rewritten. |

In other words, a file without a visible corner mark is not necessarily free of AI-identification information. Google documents these layers separately in its verification guidance.

## Why Can't I Turn Off Gemini Watermark?

Two problems are often confused: the Media Watermark option is missing, or the option exists but a watermark is still visible. Troubleshoot them separately.

![A conceptual comparison of visible media watermark controls and persistent provenance signals.](/uploads/how-to-turn-off-gemini-watermark-figure-2.png)

### If You Cannot Find the Media Watermark Setting

First confirm that you are in Gemini Apps rather than a different Google AI product. Then check these conditions:

- Location and plan: Google says users in India, South Korea, and Vietnam see this setting only with an AI Ultra subscription; otherwise visible watermarks are automatically applied to Gemini Apps visual media.
- Account: Make sure the Google account with which you generate media is the same account whose settings you are reviewing.
- App or browser: Try gemini.google.com on desktop and compare the menu with the current official instructions. Updating the mobile app is a reasonable check if its menu differs.

These checks help narrow down the issue, but they do not establish that a missing option is caused by a rollout or an account error. Follow the latest Google eligibility guidance if it remains absent.

### If a Watermark Still Appears After You Turn It Off

| **What you see** | **Likely distinction** | **Next action** |
| --- | --- | --- |
| An old downloaded image has a mark | Settings changes do not edit existing files. | Regenerate the image or edit a permitted existing file. |
| A newly generated Gemini image still has a mark | The current result may not reflect the expected setting. | Recheck the account and switch; generate one fresh test image. |
| Content from Google Flow still has a mark | Flow has its own visible-watermark control. | Check Flow > profile menu > Visible watermarking. |
| Another Google AI product still has a mark | Gemini Apps settings are product-specific. | Check the other product's controls and rules. |

If a fresh Gemini Apps creation still shows the visible mark after these checks, report the behavior through Gemini feedback. Include the product, device, account context, and file type.

## How to Remove a Gemini Watermark from an Existing Image

Turning the setting off is prevention, not retroactive cleanup. If you already have an image with a visible mark, choose a method based on whether you need to keep that exact picture.

### Option 1: Regenerate the Image with Media Watermark Off

If you still have the original prompt, turn the setting off and create another version. This avoids post-processing, but repeated generations may differ in composition, lighting, text, faces, or small details even when the prompt is identical.

Choose this route when a new variation is acceptable and you do not need to preserve the original file pixel for pixel.

## FAQ: Turning Off Gemini Watermark

### Q1: Can I turn off the Gemini watermark for free?

Google does not state a universal paid-plan requirement for this switch. However, users in India, South Korea, and Vietnam need AI Ultra to see the setting. Check your region and account against current Google guidance.

### Q2: Does the setting work for Nano Banana images?

For new images generated inside Gemini Apps, the Media Watermark setting applies to the visible mark when your account is eligible. The relevant distinction is the product interface: using Nano Banana through another Google product does not make the Gemini Apps switch universal.

### Q3: Can I use the same setting in Google Flow?

No. Google Flow has its own Visible watermarking switch in the menu under your profile picture. Changing the Gemini Apps setting does not automatically change Flow settings.

### Q4: Does turning off visible watermarking remove SynthID?

No. Google states that SynthID watermarks and Content Credentials remain. A missing visible mark alone is not proof that an image was not AI-generated; Google provides separate verification tools for supported media.

## Conclusion

To turn off Gemini watermark on new content, use Gemini Apps > Settings > Media Watermark > Off, then check a fresh creation. If the option is missing or a new file still shows a mark, review account eligibility and product settings. For an already downloaded image, either regenerate it with the setting disabled or use an authorized image-editing workflow. Neither route disables invisible SynthID or Content Credentials.
