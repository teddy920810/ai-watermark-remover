## Quick answer

Open TikTok’s public [Identify AI-Generated Content Preview](https://ai-generated-detect.tiktokv-row.com/) and submit the original local file if possible. The checker looks for supported provenance signals associated with TikTok’s AI creation ecosystem, including VeraDura and supported Content Credentials. A positive result applies to the file submitted. A missing result is inconclusive.

## Part 1. What the TikTok AI content checker can detect

TikTok’s public checker examines a local file for supported provenance signals. TikTok says it looks for VeraDura and certain Content Credentials associated with its creation ecosystem.

| **Input** | **Formats listed by the Preview** | **Maximum listed file size** |
| --- | --- | --- |
| Images | JPEG, PNG, JPG, WebP | 20 MB |
| Video | MP4, MOV, WebM, AVI | 100 MB |
| Audio | WAV, MP3, FLAC, OGG, OPUS, M4A | 100 MB |

The public page is labeled Preview. Use the visible controls and terms for your session when a format or limit differs. The provider says uploaded content is not stored on the preview page. That is a provider statement. For private or client-owned material, follow your own file handling requirements and use an appropriate authorized copy.

If you only have a social link, decide whether you can obtain the file lawfully. A screen recording captures visible playback. It ordinarily will not carry the same provenance metadata as the source file. If the only version available is a repost or a screen recording, keep that fact with your result.

## Part 2. How to use the TikTok AI content checker

### Step 1. Open TikTok’s public checker

Use the official upload page linked from [TikTok’s announcement](https://newsroom.tiktok.com/TikTok-more-tools-to-provide-clarity-and-control-around-ai-generated-content?lang=en-150). TikTok says the tool is available without a TikTok account. You should see a local file upload area, format and size information, and terms and privacy information. A cloned site that advertises a universal detector is a different service.

### Step 2. Upload the right local file

Find the earliest authorized export available and keep it as received. Record the filename and any known source. Click **Upload file** or drop the file onto the supported upload area. A forwarded clip and the creator’s export are separate pieces of evidence. If you have both and you test both, keep their results separate rather than treating them as interchangeable.

If upload fails, check format and size. Keep the original. Label any converted file as a derivative and report its result separately.

### Step 3. Record the result with the file and date

Save the visible result wording, filename and check date. Record any signal or tool it explicitly names. Keep account identifiers private when sharing screenshots.

- **Source file available:** Submit that copy first if you can share it with the checker. Save the result alongside the original filename.
- **Only a platform download available:** Describe it as the downloaded version and keep its post URL separately.
- **Only a screen recording available:** State that the check applied to the recording. A result there has a limited bearing on the original post.

See the [official checker demonstration](https://p16-headlessx-useast5.tiktokcdn-us.com/tos-useast5-i-1lgqfg6qsi-tx/0cb4f71f46e384c8a7a21bb9bde5a715.mp4) for TikTok’s own example of a supported signal result.

## Part 3. Interpret detected, no signal and processing errors

| **What happened** | **What you can report** | **What to do next** |
| --- | --- | --- |
| The checker identifies a supported signal | TikTok’s checker detected a supported signal in this copy | Cross-check the source export, file context and any visible label |
| Processing completes with no recognized signal | The checker did not identify a supported signal in this copy | Check an earlier version or use source verification |
| The file does not process | The submission could not be checked | Review format and size; do not classify the file either way |

A detected signal applies to the file you submitted. Record the exact wording and any named signal. Use the result alongside other evidence of how that copy was made. Ownership, consent and the accuracy of a depicted event require separate evidence.

A completed check with no supported signal leaves the source uncertain. A processing error, unsupported file or stalled upload leaves the check incomplete. Record those outcomes separately. For a disputed event, look for source footage, the earliest known post and independent corroboration.

If you have both the creator’s export and a social download, record one row for each file. Keep the filename, source, date, displayed wording and any named signal. A difference between the two results is a reason to check the export history. Neither result identifies what changed between versions. If the checker rejects a file, try an eligible copy only after preserving the original, and mark the new copy separately in the log.

For a result you plan to quote, record the exact supported signal if the checker names it. If the response is generic, keep that wording instead of naming a specific watermark.

## Part 4. Compare the checker, TikTok AI labels and Content Credentials

![The Content Authenticity Initiative illustrates a real Content Credentials panel on a photo. It shows a credential, rather than TikTok’s post label.](/uploads/blog-20261123/tiktok-ai-content-checker/figure-3.jpg)

*The Content Authenticity Initiative illustrates a real Content Credentials panel on a photo. It shows a credential, rather than TikTok’s post label. [Source](https://opensource.contentauthenticity.org/docs/getting-started/)*

A TikTok AI-generated content label appears in the viewing experience and may have been applied by a creator or by TikTok. The [official label help page](https://support.tiktok.com/en/using-tiktok/creating-videos/ai-generated-content) explains how that works. The public checker examines a submitted file for supported signals. A visible label on a post and a signal contained in a downloaded file can therefore disagree without either interface necessarily being wrong.

[C2PA Content Credentials](https://verify.contentauthenticity.org/) carry structured provenance information where supported. A compatible verifier can inspect the credential, but it may not read TikTok’s proprietary VeraDura signal. To understand that distinction, see the [TikTok VeraDura watermark guide](https://www.watermarkgemini.com/blog/tiktok-veradura-watermark). Likeness Detection is a different opt-in route that helps eligible people find possible matches rather than classify an uploaded file.

A short entry with the following facts makes a recheck possible.

1.  **Source:** Who supplied the file or where it was downloaded.
2.  **Version:** Original, platform copy, edit or screen recording.
3.  **Official check:** Tool used, date and exact returned wording.
4.  **Separate evidence:** Visible platform labels, available Content Credentials and any creator account of how the media was produced.
5.  **Open question:** State whether the creation process or who made the edit is still unknown.

## TikTok AI content checker FAQs

### Can I paste a TikTok video link into the checker?

The reviewed preview provides a local file upload. For a public post, record the URL separately and use an eligible authorized file where available.

### Does no detected signal mean a video was made without AI?

No. It means no supported signal was identified in that copy. An unsupported tool, a rewritten export or an absent credential can all leave you without a result.

### Does the checker replace the TikTok AI-generated content label?

No. The label is displayed on a post and has its own rules. The checker reports supported provenance signals from a file. When publishing on TikTok, follow the platform’s current disclosure guidance.
