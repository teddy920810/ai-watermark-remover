To remove a timestamp from video, first identify whether it is an editable project layer, a selectable subtitle, a player display, or text burned into the picture. Remove the original layer when possible. If the date and time are already part of the frames, use a carefully evaluated repair or crop; deleting metadata will not erase visible numbers.

This guide covers MP4 footage, VLC playback checks, a conditional online workflow with WatermarkGemini, and cropping in iMovie. Keep an untouched original. Reconstructed pixels are an estimate, so a cleaned copy should not replace the source when the exact recorded image matters.

## Part 1 Identify where the timestamp comes from

Open the same file in a second player and compare the same moment. If the numbers appear only in one application's interface, they may be a playback display rather than part of the video. Changing the player display does not require editing the saved picture.

Next check the source project, if you have it. A timecode effect, title, or date layer can be disabled before export. A stamp generated by the recording camera may already be inside each source frame. Turning off future camera stamps will not automatically change an existing recording.

| **What you find** | **Appropriate action** | **Result** |
| --- | --- | --- |
| Editable title or timecode effect | Disable or remove it in the source project | A fresh export without that added layer |
| Selectable subtitle showing time | Disable it for playback or remove the stream in a separate workflow | Picture pixels remain unchanged |
| Numbers only in the player interface | Change that application's display setting | No visual repair to the file |
| Date burned into the edge of every frame | Evaluate a crop | A smaller or reframed picture |
| Fixed burned-in stamp inside the picture | Consider local repair or AI reconstruction | Estimated replacement pixels |

Watch more than the opening frame. Some timestamps move, appear intermittently, or change position after a scene cut. A selection that works in the first shot can cover a face later. Write down the affected time ranges and whether preserving the full composition is necessary before choosing a method.

### Check selectable text in VLC

In VLC's desktop subtitle menu, select the available subtitle-track control and choose Disable. Menu wording can differ by version. If the timestamp disappears, it was being displayed through a selectable text source rather than permanently encoded into those frames.

Disabling a track affects playback. The original file can still contain that track, and another player can display it again. If the same numbers remain, investigate a burned-in stamp or another overlay source. VideoLAN's documentation explicitly states that VLC cannot disable hardcoded subtitles; the same distinction applies to timestamp-like text already in the picture.

## Part 2 Remove editable or selectable overlays

### Work from a copy of the project

Open the original editing project and save a duplicate. Move to a frame where the timestamp is visible. Select the relevant title, graphics item, or clip effect rather than altering the camera footage unnecessarily. Keep a reference frame so you can check the same location after the change.

In Premiere, Adobe documents selecting a clip and removing a selected applied effect through Effect Controls with Delete or Backspace. This is useful when the visible timecode comes from an applied effect in your project. It cannot remove numbers already present in the source pixels, and fixed effects have different removal rules.

### Export from the clean source

![Kdenlive’s title editor shows the title canvas and text controls.](/uploads/how-to-remove-timestamp-from-video/image1.png)

*Kdenlive’s title editor shows the title canvas and text controls.*

[Kdenlive — product documentation](https://docs.kdenlive.org/en/titles_and_graphics/titles/titles.html)

Disable or remove the actual timestamp layer or applicable effect, then preview all affected sections. If the stamp remains, another layer or the imported clip contains it. Do not repeatedly delete unrelated effects while guessing.

Export a new file to a distinct name and folder. Match the resolution, aspect ratio, and frame rate required by your destination where supported. Review the exported file in another player. Keep the editable duplicate so later title changes do not require reconstructing the entire project.

### Treat soft subtitle removal separately

If the VLC test removed the text, decide whether you only need clean playback or a file without that subtitle stream. For playback alone, disabling the track may be sufficient. For a distributable file, use a suitable stream-removal or remuxing workflow and confirm which streams it retains.

Removing a separate subtitle stream can avoid re-encoding the picture, but it is not a method for erasing hardcoded numbers. An MP4 extension does not establish which type of timestamp you have. Inspect the actual content before choosing a command or tool.

## Part 4 Crop an edge timestamp in iMovie

Cropping is useful when the numbers sit entirely at an edge and there is enough space around the important action. It removes picture area rather than rebuilding hidden detail. For an owned home movie with a date near an unused bottom corner, that can be a more predictable compromise than reconstruction.

### Select the clip and crop controls

In iMovie on Mac, select the clip in the timeline. Click the Cropping button, then Crop to Fill. Apple's documented crop frame for this control is constrained to 16:9, so check whether that suits the final movie before continuing.

### Reframe around the important subject

Move and resize the frame until the timestamp falls outside the retained picture. Check the beginning, middle, and end of the clip. A person walking toward the edge may be cut off even if the first frame looks correct.

Click Apply when the framing is suitable. If the crop removes essential detail, use Reset and choose another method. Do not keep zooming in simply to force the stamp out of view; excessive enlargement can make the remaining picture look soft.

## Frequently asked questions

### Will removing MP4 metadata remove the date in the picture

No. File metadata and numbers rendered into video frames are different. Use the source layer or a visual editing method for a visible timestamp.

### Can VLC save a clean version by disabling subtitles

Disabling subtitles changes playback. It does not erase burned-in text and does not necessarily remove a subtitle stream from the original file.

### Can I preserve the entire frame

Source re-export can preserve the frame when the timestamp is editable. Reconstruction may preserve dimensions, but the repaired area is estimated and can change detail.

### What if the timestamp moves

A full-duration fixed rectangle is unsuitable when the mark changes position. Use a workflow with appropriate tracking or time-specific editing, or obtain a clean source.
