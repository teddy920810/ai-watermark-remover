To export Gamma to Canva, download the original Gamma presentation as a PowerPoint file and import that PPTX into Canva in a desktop browser. Open the resulting Canva design and test a few individual objects before assuming the whole deck is editable. Keep a PDF from Gamma for comparison if the appearance matters.

A PPTX transfer is useful when you need to edit headlines, replace images or apply a Canva brand style. If you only need to show or reuse the appearance of a finished card, a high-quality PNG can be simpler. A Gamma link is useful for sharing the live presentation, while the Canva import workflow starts with the presentation file.

## Pick the right handoff for your purpose

| **What you need in Canva** | **File to start with** | **What to check** |
| --- | --- | --- |
| Edit headings or rearrange slide objects | PPTX from the Gamma source | Text and shapes are independently selectable |
| Reuse a single slide as a graphic | PNG from Gamma | Crop, pixel dimensions and readability |
| Compare imported slides against the approved version | PDF proof from Gamma | Page order, intended layout and chart labels |
| Preserve web interactions or embedded content | Keep the Gamma original alongside the Canva design | Links, static fallback and access |

Decide which parts need to stay editable before moving the deck. A training team may need to change text and translate headings, while a designer may only need each slide as a reference. For a quarterly report, chart data matters more than an exact decorative border. Write down those priorities so you can tell whether the imported result is ready.

Use a duplicate of the source for test changes. If the deck contains a special font, a dense table, a linked chart or a video embed, test a card containing those elements first. A title slide with one photograph is rarely a good test of whether the transfer will work.

## Download a PPTX from Gamma

### Review the source in Present Mode

Open the deck in a browser and verify that you can export it. View it in Present Mode, which Gamma uses as the export reference. Check title and closing cards, the densest slide, and the slide with the most unusual chart or graphic. Fix obvious overflow in Gamma before you transfer it.

If your deck contains a live chart or an interactive block, record what the destination must preserve. For a live chart, save the underlying numbers in an approved source and plan to rebuild the chart if necessary. For a web embed, prepare an approved still or a link if the imported deck cannot reproduce it.

### Export the cards as PowerPoint

Open Share and then Export, or use Gamma’s documented export action in the deck menu. Select all cards if you are moving the whole presentation. Choose the PowerPoint option and save the downloaded PPTX. If you are testing only a representative card, confirm the selected range before exporting.

## Import the Gamma presentation into Canva

### Upload the PowerPoint file in a desktop browser

![The Canva homepage example includes an Upload option in the Create menu.](/uploads/export-gamma-to-canva/image2.png)

*The Canva homepage example includes an Upload option in the Create menu.*

[Canva / SlideEgg — Screenshot source](https://www.slideegg.com/blog/canva-tutorials/how-to-import-powerpoint-into-canva-a-step-by-step-guide/)

Open the Canva account and workspace where the new design should live. Canva documents importing from the homepage by dropping the file or using Upload. You can also use the available upload action from Projects or the editor. Select the actual PPTX saved from Gamma. Wait for the import, then open the resulting design.

If the account belongs to a client or an organization, check the project location before importing. The resulting Canva design can be subject to different access and asset rules from the original Gamma deck. Use an approved workspace and restrict access to people who should edit the material.

### Verify the design and edit one object

![A sample PPTX opened in the Canva editor, with a canvas and page thumbnails.](/uploads/export-gamma-to-canva/image3.png)

*A sample PPTX opened in the Canva editor, with a canvas and page thumbnails.*

[Canva / SlideEgg — Screenshot source](https://www.slideegg.com/blog/canva-tutorials/how-to-import-powerpoint-into-canva-a-step-by-step-guide/)

Count the pages in Canva and check their order. In a copy, select a heading and change a word. Select a graphic or image separately and move it slightly, then undo. This checks whether individual parts are editable and shows how the imported elements are grouped.

Inspect the most important slide next. Compare its font, line wrapping and aspect ratio with the PDF proof. If the desired font is unavailable, select an approved substitute and recheck wrapping across the whole deck. Resizing a single text box may solve an isolated problem, but a font mismatch that affects every heading is better corrected consistently.

### Rebuild objects Canva cannot import

Canva’s import help lists charts, SmartArt, 3D objects and WordArt among unsupported items. If an important chart disappears or comes in as an image, rebuild it from the verified data or use an approved static image when updates are unnecessary. Check units, labels, the chart legend and the slide’s source note.

Inspect background and accent images separately from editable text. A scan or flattened design may look close to the source but allow only whole-image changes. If the recipient needs editable wording, recreate those few slides with actual Canva text and shapes. Use the PDF as a visual reference while you work.

## Recover from a failed import or a distorted layout

If Canva rejects the presentation, check that it is an actual PPTX and opens locally. Review Canva’s current file, page and element limits for PowerPoint imports. Test a smaller portion from Gamma to identify a size limit or troublesome card. Use the web export workflow for finer control when you need to isolate the issue.

If only one card is distorted, compare three versions side by side. First look at the Gamma presentation view, then the PPTX and finally the Canva design. This tells you where the difference began. Fix a clipping issue in Gamma if it exists before export. If it appears only in Canva, adjust the imported object or rebuild it there.

Before sharing, check the slide count, any replaced data, and the final presentation view. Give the recipient the editable Canva design and, if useful, a PDF proof. Keep the Gamma link when they also need the live original. Tell collaborators which copy should receive changes so the two decks do not drift.

## Frequently asked questions

### Can I paste a Gamma link into Canva to import the slides

The documented file workflow uses a PowerPoint export from Gamma and an import of that file into Canva. Ask the owner for an authorized PPTX if you lack export access.

### Will all Gamma slides stay editable

Some objects may remain selectable, while unsupported objects can be missing or flattened. Test text, images and tables on the actual imported design.

### Can I use a PDF instead of a PPTX

A PDF is helpful as an appearance proof or fallback. Start with PPTX if individual slide objects need to remain editable.

### Why did the font change after import

Canva may substitute a font when an exact match is unavailable. Use an approved available font and check line wraps and spacing before you present.

## Conclusion

Export PPTX from the authorized Gamma source, import it in Canva and check what you can edit. Keep a reference copy and rebuild the few objects that cannot survive the transfer.
